⏸️ Pause all saves

For a short maintenance (for example while the developer corrects the sheet by hand). While paused, nobody can save anything: staff see "Saving is paused", the student app shows "School data is being updated". Pages can still be opened, people can still log in and Backup Now still works. Tap Resume when you are finished.

⏱️ Speed check

Times the main pages one by one on your own data (about 1–2 minutes). Green is quick, orange is slow, red needs fixing. Below it you see the slow requests that real users met. Run it when few people are using the app.

🧑‍🎓 Student data check

Reads the current student list (sheet tab "Students") and lists what the school must correct: wrong or empty birth dates, missing or repeated admission numbers, unknown classes, repeated roll numbers. It changes nothing. Send the list to the school.
